## T02.01 工具权限与宿主契约

证据记录在 `feedback/W01-Core工具与Reply-feedback.md`。

- [x] **A01 · Core JVM** 工具可见范围和执行访问一致，逐调用 ID 回填。未知工具、失效安装、重复 ID、非法入参、取消或超时按约定终止或返回受控结果，无越权副作用。
- [x] **A05 · Core JVM** 合成消息中的身份、来源、会话、目标、引用和五类媒体能通过公共契约。模型投影只消费支持的数据，测试不接触 Android 或具体插件。

## T02.02 非流式 Reply 与上下文

证据记录在 `feedback/W01-Core工具与Reply-feedback.md`。

- [x] **A02 · Mock HTTP + Core JVM** 主模型请求明确为非流式。一次 Reply 含多条，或连续 Reply 穿插普通工具，工具按序回填，入队确认后继续循环，普通正文和未经筛选的工具结果不外发。
- [x] **A03、A15 · Core JVM** 空白 STOP 无助手消息，成功静默输入仍参与后续上下文和历史读取；缺有效 Reply 与工具不兼容有受控状态；视觉、压缩和取消各回归一条实际路径。

## T02.03 会话持久化与投递队列

证据记录在 `feedback/W02-Android会话与投递-feedback.md`。

- [x] **A03–A05 · Room/Android 集成** 持久提交先于工具成功。多条 Reply 和逐目标状态可独立查询，私有资源引用稳定，生成结束仍能取消待发。
- [ ] **A04、A15 · Room/Android 集成** 重开恢复有效待发、取消中断轮次待发。新输入、停止与检查点回退取消对应旧消息；已送达不重发，未知不自动重发；确认失败只重试指定消息和目标。检查旧数据库读写和并行会话。

## T02.04 宿主接线、平台路由与调度入口

证据记录在 `feedback/W02-Android会话与投递-feedback.md`。

- [ ] **A05、A07、A09 · 宿主合成适配器/Android** QQ 本人绑定接续主会话，普通私聊和群独立。同一平台/账号入站和消息读取与源路由授权一致，停用立即撤销登记，普通回复送原触发目标。
- [ ] **A05 · 正式宿主适配入口** 通过 T02.08 的五类媒体样本核对稳定资源引用、会话授权和模型投影。支持的类型可达对应能力，不支持的类型返回可观察状态，无法读取未获准资源。
- [ ] **A10、A11 · 宿主合成适配器/Android** App 主会话允许任务动作，外部入口/专属会话以及失效确认无法执行。排队及重复回调不增轮次；首个 Reply 快照全体授权目标，其中一个失败或授权失效不影响其他目标，App 历史只出现一次。
- [x] **A14 · App 装配检查** 普通启动与手动检查可调用同一真实版本检查服务，具备启动去重和检查失败状态。

## T02.05 插件制品、运行时与生命周期

证据记录在 `feedback/W03-插件底座与分发-feedback.md`。

- [ ] **A06 · 依赖、APK 及 ARM64 原生验证** 基础 APK 独立启动并只包含核准的原生启动组件。APK 无可选插件实现、Ubuntu rootfs、Linux QQ、NapCat 及专用资源；正式宿主能调用安装目录原生程序执行最小 Ubuntu 命令。
- [ ] **A01、A06、A07、A17 · 正式 App + 签名合成插件** 私有目录只读加载、首装启用及失败重试、已安装版本升级、错误签名/API/ABI 拒绝、初始化失败留旧、禁用/删除/重装均按任务书产生可见状态，旧身份失效。

## T02.06 官方目录、双源下载与 App 更新

证据记录在 `feedback/W03-插件底座与分发-feedback.md`。

- [ ] **A12、A13 · 合成目录与 HTTP** GitHub 权威元数据已验证，主文件传输失败且 Gitee 字节与签名目录一致时，才可用备用文件。截断、签名或摘要错误、版本不符及同名异包被拒绝，已安装插件可用。Agent 只读查询，安装等动作不具备模型入口。

## T02.09 主会话定时任务

证据记录在 `feedback/W05-主会话定时任务-feedback.md`。

- [ ] **A07、A10、A17 · 插件定向测试** 两入口共享一个任务记录。普通私聊、群、专属会话及 QQ 无任务管理能力。模型写入经确认，拒绝或失效的确认不生效。立即运行记录独立且保留原计划。

## T02.12 正式入口集成与交付

证据记录在 `feedback/W07-集成与验收-feedback.md`。

- [ ] **A01–A05、A15 · 真实模型与 App + 定向回归** 有真实兼容模型在 App 中生成分条 Reply。异常、历史、旧数据升级和清理通过必要的合成/Android 验证。引用仍有效的前序证据，核对旧流式正文出口已从用户链路退出。
- [ ] **A06–A11、A17 · 受支持 ARM64 与合成补充** 从正式基础 App 安装两类签名插件并核查实际 APK；真机登录和 OneBot 私聊/群聊往返，锁屏或后台与重连；实际系统触发进入主会话。QQ 加合成的第二目标与零外部目标各验证一次，任务只生成一轮、独立投递，失败与未知受控。覆盖重启、禁用及 15 分钟恢复。
- [ ] **A12–A14 · 真实制品/发布端 + 反例** 有效 GitHub/Gitee 资产为同一制品。核对正式 App 签名更新和错误签名保留旧包，版本和错误状态正确。发布操作遵循用户授权。
- [ ] **A16、A17 · 正式 App 入口** 首装和升级的 FAQ、模型配置、插件连接及任务引导走通。
- [ ] **A01–A17 · 审核与用户验收** W08 逐项检查行为、共享边界、测试和证据等级，问题修复复验后关闭。W07 汇总可验收产物和最短操作步骤。用户反馈对应检查后再勾选用户验收。审核证据同时记入 `feedback/W08-独立审核-feedback.md`。
