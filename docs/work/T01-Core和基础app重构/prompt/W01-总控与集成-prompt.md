负责共享构建、Manifest、共享契约和最终入口，收尾更新文档及索引。其他实现返工按文件归原 Worker。 遇到影响已确认范围、语义或验收的冲突，保留证据，交 W01 处理。依照 [Checklist](../T01-Core和基础app重构-checklist.md)核验负责的 T01.01、T01.08、T01.09，未通过或未运行的项保留原因。执行后写入 `../feedback/W01-总控与集成-feedback.md`，包括实际改动、操作或命令、环境与产物、结果和对应条目。
