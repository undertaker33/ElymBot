# T01-Core 和基础 App 重构 Checklist

按 [任务书](T01-Core和基础app重构.md)「用户验收」表的行序引用验收场景。证据写入对应 Feedback，实际运行并满足条件后勾选。T01.08 中实际模型与设备验证单列，合成证据不能代替。

## T01.01 模块基线与交接契约

- [x] 任务书模块边界。方法：编译和依赖图。通过条件：Core 能作为 JVM 模块编译，App 通过共享接口装配；依赖边界符合 Spec。
- 证据：`feedback/W01-总控与集成-feedback.md` 的 T01.01 条目。

## T01.02 模型适配、能力探测与 SSE

- [ ] 用户验收 2–5。方法：JVM 合成 HTTP/SSE；暂停结束帧。通过条件：三项探测含不可判定状态；首片先到、分帧空白/UTF-8 保留；流式工具参数拼全后才形成调用；普通响应、EOF 和取消分明。
- 证据：`feedback/W02-模型适配-feedback.md` 的 T01.02 条目。

## T01.03 上下文装配、预算与压缩

- [ ] 用户验收 8。方法：注入小预算、摘要响应与超限错误。通过条件：能按完整边界压缩，覆盖范围、降幅和再次触发可验证；失败保留旧摘要，必要材料仍超限时受控结束。
- 证据：`feedback/W03-Core运行-feedback.md` 的 T01.03 条目。

## T01.04 顺序 ReAct、工具底座与指令规则

- [ ] 用户验收 5、6、8。方法：合成多轮模型、工具来源与指令输入。通过条件：按序执行并逐 ID 回填；拒绝、失败、取消与限量有受控结果；反馈是助手文本；名字冲突和错误编号本地反馈；视觉直答与转述路由可区分；超限恢复复用已完成的工具结果。
- 证据：`feedback/W03-Core运行-feedback.md` 的 T01.04 条目。

## T01.05 Android 本地数据与检查点

- [ ] 用户验收 1、2、6–8。方法：Android 存储测试，含重启与事务故障。通过条件：主会话唯一，专属会话固定归属且按人格查询。各会话历史、人格、模型与指令可持久化，凭据只交认证；回退删除消息、附件引用、相交摘要和后续检查点，同轮锚点按建点顺序删除；重建显示编号正确，事务失败全量回滚。
- [ ] 用户验收 9、10。重启复查两种图片位置。批量删除所选会话及关联记录，保留未选会话，名下仍有会话时阻止删除人格。
- 证据：`feedback/W04-Android数据与会话-feedback.md` 的 T01.05 条目。

## T01.06 App 会话服务与持久化接线

- [ ] 用户验收 1、3、4、6–8。方法：经会话服务运行合成一轮和失败重试。通过条件：停止和迟到事件按会话隔离，重试无重复用户消息。回退只删除当前会话的尾部，HistoryRead 与请求只能读取该会话仍保留的历史。
- [ ] 用户验收 9、11。编辑后下一轮读取最新人格。A 发出首段后离开页面，B 同时生成，A 继续接收并保存回复。停止 B 时 A 不受影响。返回 A 显示当前内容或完整回复，消息与未读状态归属各自会话。
- 证据：`feedback/W04-Android数据与会话-feedback.md` 的 T01.06 条目。

## T01.07 原型界面、资源与 ViewModel

- [ ] 用户验收 1–6。方法：从 App 导航对照 v0.6.3 与任务书补充项。通过条件：主会话可切人格，专属会话只能从对应人格进入且归属固定。人格、聊天、模型配置、三项探测和指令改名可达，附图和键盘操作可用；指令列表、回执和工具反馈纯文本。
- [ ] 用户验收 9–11。界面可分别预览和保存封面、头像位置，可批量删除专属会话，可看到并清除对应会话的新消息提示。
- 证据：`feedback/W05-Android界面-feedback.md` 的 T01.07 条目。

## T01.08 正式入口、端到端与插件隔离

- [ ] 用户验收 1–11 与 APK。方法：正式 App 操作、合成端点和依赖/APK 检查。通过条件：释放第二段前首段已经可见；验证非流式、停止、断流、视觉两路、回退、双会话并行、离开后回复完整落盘、批量删除、新消息提示和图片位置；App 的结构化能力判定能使请求带上 HistoryRead 定义，压缩后能回读并续答，回退后无法读回；依赖与 APK 无可选插件实现和专用资源。
- 证据：`feedback/W01-总控与集成-feedback.md` 的 T01.08 条目。
- [ ] 用实际验收服务和 Android 设备完成模型探测与正式对话，注明模型、设备和 APK。

## T01.09 交付与状态同步

- [ ] 用户验收与交付物。方法：核对 APK、记录、状态和用户反馈。通过条件：可按最短路径复现；证据能对应每项，未验证项有原因；用户验收及包级状态按实际结果维护。
- 证据：`feedback/W01-总控与集成-feedback.md` 的 T01.09 条目。
- [ ] 用户完成任务书约定的最终验收，记录实际反馈。
