# T01-Core 和基础 App 重构 Spec

## 目标与依据

交付可独立运行的原生 Android 基础 APK。用户按指定原型管理人格和模型、在全局主会话和人格专属会话中进行文字与图片对话、控制生成并用指令管理检查点。宿主 Agent 可用内置 HistoryRead 读取仍保留的会话原文。

以 [任务书](T01-Core和基础app重构.md)和 [高保真原型 v0.6.3](ElymBot_高保真原型.html)为交付基准，以 [详细设计](T01-Core和基础app重构-详细设计.md)为实现参考。检查点以任务书确认的彻底删尾为准。浏览器 SSE、SQLite 和参考仓合成测试仅作探索证据。批量删除、并行回复、新消息提示及封面和头像位置调整按任务书补齐。阶段完成以本包正式入口、APK 和验收证据为准。

## 交付边界

| 归属 | 交付 |
| --- | --- |
| Core | Kotlin/JVM 宿主 Agent，顺序 ReAct 和结构化工具回填；OpenAI 兼容模型适配、三项探测、原生流式与普通响应、视觉直答或先转述再由主模型回答；上下文预算、自动压缩及超限恢复；五项指令行为；内置 HistoryRead。 |
| 基础 App | 参照原型的人格库、编辑、聊天和模型配置，全局主会话与按人格入口访问的专属会话；指令改名入口；Room 本地会话与摘要，私有附件和按服务保存凭据；会话运行、停止、重试、检查点删除和恢复后的状态展示。 |
| 插件底座 | 工具来源登记与筛选、执行范围、结果及取消契约。HistoryRead 与测试来源走同一入口。基础 APK 依赖与实物均排除插件实现和专用资源。 |

## 行为约束

- 人格和模型设置在一轮开始时确定，结束后可在当前会话建点或回退。App 固定保留一个可切换人格的全局主会话。专属会话创建时固定归属人格，只从该人格入口创建和打开。专属会话每轮读取所属人格的最新配置，生成中使用本轮快照。不同会话可同时生成，离开聊天或切换会话时继续接收并持久化回复。新回复到达后在应用内提示对应会话。用户可见文案资源化。
- 专属会话支持单条和批量删除，处理完名下会话后才可删除人格。封面和头像的位置分别调整、分别保存。
- 支持流式的模型在终止前交付增量，仅支持非流式的模型完整返回后显示。停止和断流保留已显示的文字并标状态。重试复用原用户消息，清理该次失败产物后再交付。有效的模型配置是实际聊天的前置条件。
- 五种 Slash Command 本地执行，名称可改，参数用空格分隔。`/persona` 只在主会话可用。`/help` 显示当前会话可用指令和删除范围。回退直接删后续，每个会话的固定空点为 1，`/reset` 回当前点，`/mark` 以已完成轮次建点，后续编号可复用。回退以同一事务处理会话记录与相交摘要。
- 压缩保留原文。HistoryRead 只访问当前会话仍保留的记录，返回有界的原文和定位信息。助手工具反馈走普通文本气泡，结构化结果按调用 ID 交模型。
- T01 使用可测试的预算、限时和限量默认值，详细设计中的具体数字可按验证调参。受任务书和现有功能约束的实现细节由负责人收敛。

## 范围外

QQ、语音、MCP、定时任务等具体插件，独立 Bot 档案，旧数据迁移，深浅色、语言切换、应用更新、备份恢复、诊断与缓存管理等后续原型能力。平台与插件导航沿用原型禁用态。外部模型协议和第三方 SDK 另议。

## 验收

按 [Checklist](T01-Core和基础app重构-checklist.md)取得 Core JVM、Android 存储与正式入口验证、运行时依赖图和 APK 内容的证据，提供 APK、最短验收操作和可复现记录。最终用户验收按原任务书。
