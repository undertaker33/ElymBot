## 开始一项任务

正式任务复制[任务书模板](workflow/templates/任务书模板.md)，填好后交给 Agent。几句话能说清范围与完成标准的任务，可以直接在对话中下达。两种方式均由 Agent 使用[任务记录模板](workflow/templates/任务记录模板.md)留下结果。
