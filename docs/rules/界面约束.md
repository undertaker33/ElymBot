# 界面约束

现有[高保真原型](../work/T01-Core和基础app重构/ElymBot_高保真原型.html)作为 App 视觉基础；后续已确认的约束优先于原型。本文未规定的具体样式与实现细节留给实现设计。

## 页面、导航与动效

- 所有一级页面标题使用相同字体和字号。
- 各页面的滚动跟随行为连续对应用户的实际滚动位置。内容未溢出可视区域时，页面不滚动，顶部区域不收起。
- 点击现有放大镜与滚动触发相同的连续搜索变形。点按展开时，内容随标签区域收缩上移。搜索框与聊天页单行输入框同高，展开后宽度接近内容区全宽。
- 保留悬浮半透明搜索入口和底部导航。两者遵守系统安全区域，文字与图标清晰可辨。
- 人格表单和检查点弹层限制最大高度。标题固定，超出可视区域的内容在弹层内滚动。快速上滑到达内容边界时，弹层保持在展开位置。短距离下拉后弹层回到原位。
- 转场保持缓慢且可感知，并遵从系统减少动态效果的偏好。页面间的动效和视觉风格保持一致；具体时长由实现设计确定，本文不预设数值。

## 配置与人格

- 配置页当前固定为「模型」「上下文」「工具」三个分类，以[现有功能盘点](../product/ElymBot-重构前功能盘点.md)为依据。
- 模型配置从主界面底部的「配置」打开。聊天中的模型提示指明返回主界面后的配置入口。
- 人格页的固定筛选为「全部」和「收藏」。新增标签入口放在最右侧，与标签项等尺寸。新增标签后保留原筛选。
- 人格页可长按自定义标签并确认删除。删除会解除所有人格与该标签的关联。删除当前筛选的标签时回到「全部」，其余情况保留当前筛选。
- 新建和编辑人格使用保留背景可见的底部弹层。表单依次显示基本信息、提示词、图片和使用方式，收藏和全局人格使用开关。标签支持多选，标签较多时使用带搜索和已选筛选的滚动弹窗。提示词区只显示标题和输入框。输入框以紧凑高度开始，随内容长到上限后在框内滚动。
- 设置页各分组入口等尺寸，当前分组的详细内容在分组内部展示。
- 设置页的「关于」入口可搜索，打开独立页面。页面居中展示应用图标、名称、当前安装版本和 MIT 许可，并提供源代码、发布记录和开源许可链接。页面返回操作回到设置页。
