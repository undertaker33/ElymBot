# 界面约束

现有[高保真原型](../work/T01-Core和基础app重构/ElymBot_高保真原型.html)作为 App 视觉基础；后续已确认的约束优先于原型。本文未规定的具体样式与实现细节留给实现设计。

## 页面、导航与动效

- 所有一级页面标题使用相同字体和字号。
- 各页面的滚动跟随行为连续对应用户的实际滚动位置。内容未溢出可视区域时，页面不滚动，顶部区域不收起。
- 点击现有放大镜与滚动触发相同的连续搜索变形。搜索框与聊天页单行输入框同高，展开后宽度接近内容区全宽。
- 保留悬浮半透明搜索入口和底部导航。两者遵守系统安全区域，文字与图标清晰可辨。
- 转场保持缓慢且可感知，并遵从系统减少动态效果的偏好。页面间的动效和视觉风格保持一致；具体时长由实现设计确定，本文不预设数值。

## 配置与人格

- 配置页当前固定为「模型」「上下文」「工具」三个分类，以[现有功能盘点](../product/ElymBot-重构前功能盘点.md)为依据。
- 人格页的固定筛选为「全部」和「收藏」；用户自定义标签在编辑人格时选择。新增标签入口放在最右侧，与标签项等尺寸。
- 设置页各分组入口等尺寸，当前分组的详细内容在分组内部展示。

## 应用图标

启动器和系统启动页共用用户提供的 [icon.png](../../app/src/main/res/mipmap-nodpi/icon.png)，启动器在 Manifest 引用 `@mipmap/icon`。
