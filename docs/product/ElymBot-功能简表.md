# ElymBot 功能清单

依据当前新版决策整理。 [完整功能盘点](ElymBot-重构前功能盘点.md)

- 人格库是主要视觉展示入口，可浏览、搜索和按标签筛选人格。
- 创建和编辑人格的名称、标签、封面和提示词。具体浏览及裁剪交互待定。
- App 只有一个全局主会话。可以保存多个人格预设并激活其中一个，切换后仍接续同一段对话。
- 手动选择 QQ Bot 和本人 QQ 聊天账号完成绑定后，首版可在 App 与对应 QQ 私聊中接续同一主会话。
- 在 App 查看所有 QQ 群聊和其他 QQ 私聊的历史。外部会话自动隔离，App 内只读。
- 查看聊天历史、清除当前上下文，或按时间激活历史切片并从该处继续。
- 回复生成结束后可切换人格、清除上下文或激活其他历史切片。
- 与助手进行文字和图片对话，查看流式回复。
- 助手可以在对话中调用工具，并根据结果继续回答或处理任务。
- 创建和管理 Bot，选择默认人格并绑定接入账号及配置。
- 复用 Bot 的行为配置。独立配置入口待定。
- 添加和管理模型服务、密钥与模型，拉取模型列表并查看能力探测结果。
- 为聊天、视觉、语音识别和语音合成选择模型。会话内模型切换的范围待定。
- 按需独立下载、安装和删除插件，包括 QQ 接入、语音、定时任务和工具插件。
- 通过 QQ 接入插件登录、切换和退出账号，查看接入和安装状态。
- 通过 QQ 群聊和私聊收发文字、图片与语音，支持引用回复和 @。
- 配置 QQ 唤醒、白名单、管理员绕过、关键词、自动回复、群内会话隔离、限频和暂存重放。
- 通过对话指令管理 Bot、会话、模型、人格、语音和 QQ 权限。
- 使用云端语音识别进行转写。
- 使用云端语音合成回复，选择音色并试听。新版加入 MiMo TTS。
- 在应用内导入参考音频，调用云端服务克隆音色并选用。App 聊天录音与气泡播放待定。
- 安装定时任务插件后，可在对话中用自然语言创建和修改任务，到点执行并将回复发回所属会话对应的渠道。
- 查看和直接编辑任务名称、提示词、频率、间隔、重复结束条件，暂停或恢复任务并查看运行记录。面板位置和 QQ 创建入口待定。
- 接入远端 MCP 工具，查看当前可用的工具。工具管理入口待定。
- 集中查看接入、任务、更新和下载的运行状态与故障，从对应功能处理。
- 查看和复制日志，清理运行缓存，查看资源占用。
- 检查应用更新，查看下载进度、重试并安装更新。
- 切换应用语言和外观主题。
- 备份与恢复新版数据。具体覆盖范围、导入方式和自动备份待定。
