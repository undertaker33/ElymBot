# ElymBot 重构待办清单

本表追踪[旧版功能盘点](product/ElymBot-重构前功能盘点.md#一完整功能清单)中的 F001–F059，以及新版的关键行为变化。旧版状态和源码证据见各 F 项，D01–D16 见[产品决定](product/ElymBot-重构前功能盘点.md#五需要用户决策的事项)。与旧决定有差异的 T01 行为以[T01 任务书](work/T01-Core和基础app重构/T01-Core和基础app重构.md)为准。

截至 2026-11-13，新版源码提供 Android 启动页，以及 Core、QQ 和定时任务的模块骨架。**已完成** 表示新版有正式入口并有对应验收证据，目前这 59 项中尚无已完成项。**待完成 · T01** 表示已列入 [T01 实施任务](work/T01-Core和基础app重构/T01-Core和基础app重构-tasks.md)，**待完成 · 后续** 表示已保留且后续实施，**待定** 表示行为或范围仍需确认，**暂缓** 表示本轮延后，**已弃置** 表示新版已决定舍弃旧能力或旧形态，**拆分** 表示同一旧项有多种后续去向。验收后按 [工作包状态](Context-Index.md#current-status)和对应 Checklist、Feedback 更新。

## 关键差异与新增能力

| 事项 | 旧版与新版差异 | 实际进度、依据与接续 |
| --- | --- | --- |
| 主会话与人格专属会话 | 新版固定保留一个可切换人格的主会话。专属会话创建时固定人格归属，只从对应人格入口进入。历史、摘要与检查点按会话隔离。每轮读取所属人格最新配置，支持批量删除、会话并行回复和应用内新消息提示。 | 待完成 · T01。按 v0.6.3 和任务书补充项验收。 [界面实现基准](work/T01-Core和基础app重构/T01-Core和基础app重构-详细设计.md#7-界面实现基准) |
| 单一宿主与顺序 ReAct | 旧宿主已有多轮工具闭环，也有插件独立 Agent 和事件链。新版以一个集中、顺序的循环持有本轮状态，收齐并校验工具调用后顺序执行，逐个按调用 ID 回填，支持停止、超时和执行上限。 | 待完成 · T01。按[单轮执行设计](work/T01-Core和基础app重构/T01-Core和基础app重构-详细设计.md#61-单轮执行)验证正常、拒绝、失败与取消。 |
| 历史预算与自动摘要 | 旧版主要按配置控制历史窗口，并有摘要工具。新版每次模型调用前重算预算，按需摘要较早完整轮次和已完成的工具批次，校验覆盖范围和预算降幅。 | 待完成 · T01。依据[压缩步骤](work/T01-Core和基础app重构/T01-Core和基础app重构-详细设计.md#52-压缩步骤)验证压缩、裁剪回退和原文保留。 |
| HistoryRead | 新增随基础 APK 提供的内置工具。模型可以按范围分页读取当前会话中仍保留的原文，包括摘要覆盖的原文。 | 待完成 · T01。验证压缩后可回读、会话间隔离、回退删除内容无法回读，以及工具结果回填后模型继续回答。 [HistoryRead 设计](work/T01-Core和基础app重构/T01-Core和基础app重构-详细设计.md#53-historyread) |
| 固定行为与自定义 Slash Command | 旧版包含多会话、Bot、语音和平台管理等命令。新版首批提供帮助、人格选择、检查点选择、重置和建点，可改名称，参数用空格分隔。人格与检查点采用纯文本编号。 | 待完成 · T01。按[指令与检查点事务](work/T01-Core和基础app重构/T01-Core和基础app重构-详细设计.md#4-指令与检查点事务)验证改名、无效输入和正在生成时的限制。 |
| 用户检查点和实际删尾 | 固定空点编号为 1，`/mark` 在完整轮次建点。`/checkpoint N` 回到指定点，`/reset` 回到当前点。两条回退指令直接执行，彻底删除点后的对话、检查点及相关记录，覆盖已删内容的摘要一并清理。显示编号可重新使用。 | 待完成 · T01。以[任务书用户验收](work/T01-Core和基础app重构/T01-Core和基础app重构.md#用户验收)的 A–F 场景验证删尾、编号复用、重启和空点。 |
| App 真流式、停止和重试 | 旧 App 交付链会等模型请求结束再分段。新版要求模型文本增量到达即更新同一气泡，非流式模型完整返回后显示。停止和断流保留已显示文字并标记，重试复用原用户消息。 | 待完成 · T01。用分时合成 SSE 验证首段先于结束帧显示、停止和断流。 [SSE 与 Compose](work/T01-Core和基础app重构/T01-Core和基础app重构-详细设计.md#63-sse-与-compose) |
