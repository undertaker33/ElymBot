# ElymBot v0.1.0

ElymBot v0.1.0 带来了文字和图片对话、可自定义的人格，以及可以同时进行的多场对话。首次使用时，先创建一个人格，再到「配置」添加 OpenAI 兼容服务并选择主模型。

## What's Changed

### 人格和会话

- 在人格库自定义名称、简介和提示词，分别调整封面和头像的位置。可以搜索人格、加入收藏和按标签筛选。长按自定义标签可以删除，删除后会从所有关联人格上移除该标签。
- 主会话可以切换人格。设为全局人格后，点其卡片可打开主会话。其他人格的卡片打开各自的专属会话列表，专属会话始终使用创建时所属的人格。
- 多个会话可以同时生成。切换会话或离开聊天页后，回复仍会继续生成并保存。有未读回复时会显示新消息提示，也可以批量删除专属会话。

### 聊天和模型

- 支持添加 OpenAI 兼容服务、从服务拉取模型或手动填写模型 ID，并检测模型的可用性、视觉和流式能力。
- 聊天输入框旁的「＋」可以添加图片。主模型支持视觉时直接看图回答，否则由已配置的视觉模型转述图片，再交给主模型回答。
- 支持原生流式的模型会边生成边显示回复，其余模型在回复完成后一次性显示。停止生成或连接中断时会保留已显示的内容，中断后可重试。

### 历史、检查点和指令

- 长对话会自动压缩较早的内容以腾出上下文。原始对话仍可在会话中查看，模型也可以通过内置的 `HistoryRead` 工具回读仍保留的历史。
- 用 `/mark` 保存最近一轮完整对话后的检查点。用 `/checkpoint` 查看检查点，或在聊天菜单打开检查点列表。回到指定检查点会删除该点之后的对话和后续检查点。`/reset` 回到当前检查点，`/checkpoint 1` 清空当前会话。
- 在输入框输入 `/` 可查看并选择指令。`/help` 显示用法，`/persona` 列出人格，例如在主会话发送 `/persona 1` 切换至第一个人格。指令名称可以在设置中自定义。

### 外观和导航

- 支持跟随系统、浅色和深色主题。一级页向上滚动时，顶部标题和标签逐渐收起，露出悬浮搜索框。也可以点击搜索按钮直接展开。
- 底部导航支持点按和横向拖动，松手后切换到最近的页面。「关于」页可查看已安装的版本和项目链接。

## Downloads

支持 Android 8.0（API 26）及以上版本。

- `ElymBot-v0.1.0-release.apk` 适合日常使用。
- `ElymBot-v0.1.0-debug.apk` 用于调试，可与正式版同时安装。
